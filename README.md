# Cat-Odyssey
#
內容與互動
首頁：貓咪的眼睛會跟著滑鼠轉，也會眨眼。點牠會發出喵叫聲、冒愛心並增加親密度，上方的按鈕可以換花色。

品種圖鑑：收錄米克斯、英短、布偶、緬因、暹羅、波斯、摺耳、孟加拉 8 種，可篩選長短毛。點選後會看到體型、壽命、活潑／黏人／掉毛／照顧四項評分，以及飼養提醒（例如摺耳的健康風險）。

花色：10 種花色，每種附一則小知識，例如橘貓多為公貓、三花多為母貓。按「讓首頁的貓換上」就能套用到首頁那隻貓。

性格測驗：4 題問答，配對最適合你的品種，結果可跳到該品種的詳細資料。

生活區域：點窗台、跳台、紙箱、飯碗、貓砂盆，貓咪會走過去並說明牠為什麼喜歡那裡。下方另有室內家貓、半戶外、街貓與 TNR 的說明。

一起玩：用滑鼠或手指移動紅點，貓咪會追，追到加親密度。另有「叫牠一聲」和「餵零食」按鈕。
